# Design Episode 结构与检索约束

## 目的

把一次硬件 Agent 调优中可复用的因果信息保存为可检索对象，使后续 Agent 先读取少量相关证据，再决定查看源码、生成 RTL、运行差分验证或调用 EDA。Episode 不是完整聊天记录，也不能代替重新验证。

## 字段

| 字段 | 含义 | 是否可用于盲盒实验 |
|---|---|---|
| `episode_id` / `schema_version` | 稳定标识和格式版本 | 是 |
| `knowledge_class` | `cross-target-process-memory` 或 `target-specific-solution` | 是 |
| `access_policy` | 允许、禁止使用的实验组及原因 | 是 |
| `target` | 模块、配置、文件和工具链边界 | 仅同目标复用组 |
| `objective_and_invariants` | 优化目标、不可改变的行为和资源门禁 | 可抽象后跨目标使用 |
| `agent_dependencies` | 源码、生成 RTL、原始 EDA、差分与回归之间的依赖关系 | 是 |
| `evidence_to_hypothesis` | 原始现象、源码结构和可证伪根因假设 | 仅同目标复用组 |
| `search_history` | 候选变换、失败、修复和被接受的原因 | 仅同目标复用组 |
| `validation` | 功能、综合、布局布线及整机回归证据 | 是，但不能当作新候选结果 |
| `applicability` | 正向检索词、前提和禁止外推范围 | 是 |
| `cost` | token、EDA 次数和墙钟时间 | 是 |
| `provenance` | 源运行、哈希和原始证据路径 | 是 |

## 三种实验隔离

- **K0 无记忆**：不暴露知识索引，作为原始盲盒结果。
- **K1 通用过程记忆**：只检索跨目标的验证、失败恢复和证据使用规则；不得出现当前模块的根因或变换。
- **K2 同目标结构记忆**：允许检索当前模块的原始症状、根因假设、适用条件和历史验证；用于测量知识复用效率，不能称为盲盒发现。

## 检索协议

1. Agent 先用短查询搜索索引，只返回 episode 元数据、可用字段和检索词。
2. Agent 显式选择 episode 和最多六个字段，正文设置字符上限。
3. 每次搜索与读取记录查询、字段、响应长度和内容哈希。
4. 记忆中的结论必须重新通过功能差分、Vivado PPA 和独立回归；历史结果不能直接晋升为新结果。
5. K1 若暴露当前目标答案，或 K2 未读取目标 episode，均视为协议偏差，不并入正式对照。

控制器提供可选的 `--auto-stop-improvement-percent`。只有候选已经通过功能、面积和后综合门禁，且相对冻结基线达到预先声明的改善阈值时才停止搜索；随后仍执行独立差分、布局布线和整机回归。阈值必须在实验前冻结，并对比较组一致，不能根据中途结果调整。

## 效率判定

先要求候选 `final_valid`、面积合格，且后布局布线延迟相对 K0 不劣化超过 2%；随后比较首次编辑/评估回合、模型总 token、搜索墙钟和 EDA 候选数。主要门槛是 token 与搜索墙钟均减少至少 30%，强门槛是两者均减少至少 50%。

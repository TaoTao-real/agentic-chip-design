# 论文与项目调研

核对日期：2026-09-24。状态：有来源的研究笔记与工程建议，不是已实现能力清单，也不是独立复现实验报告。

本目录将项目讨论整理成可逐项更新的材料。每篇笔记区分：**原工作支持的事实、对本项目的分析、建议验证的机制和未解决的问题**。不直接复制聊天中的性能数字或 API 推测。论文固定到所读版本；仓库默认分支材料注明尚未固定 commit，采用前必须再次锁定版本。详见 [来源与核验范围](sources.md)。

## 与项目架构的关系

本目录不新增与现有架构平行的一套平台。对应关系仍是：

| 领域模块 | 可吸收的研究机制 |
|---|---|
| Design Core | PyCircuit 原生语义与来源；CAKE/XLS 的表示和检查经验 |
| ChipContext | 确定性提取、证据关联、有限查询；可选判断模型排序 |
| Loop Engine | CHIA 执行适配；可替换 WorkspaceBackend；受控 SearchPolicy |
| KnowledgeStore | 带出处和适用条件的 Episode，派生可回放 SearchTrace |
| 离线慢循环 | RRSI 式约束与 Dream-RSI 式回放筛选；真实评估后发布新版本 |

这是一组**待验证的组合建议**，并非上述项目已经联合实现。原有职责以 [总体架构](../architecture.md)、[数据契约](../data-contracts.md) 和 Proposed 状态的 [ADR](../adr/README.md) 为准。

## 共同评价原则

最终目标是同一主模型在冻结任务与门禁下，更低成本地交付经过独立验证的设计。专家 Prompt、Agent 自写解析脚本、确定性清单和现有文件系统机制都是允许的强基线。辅助模型、离线策略开发、回放、工作区物化、失败重试和最终验证成本都要计入；不能只报告输入 token 或成功样本。

外部 GPU kernel、软件任务或训练数据筛选的结果，不直接构成本项目的 FPGA/ASIC 优化证据。具体消融见 [评估协议](../evaluation.md)；实施任务仍由 [BACKLOG](../../tracking/BACKLOG.md) 跟踪。

## 知识隔离与维护

**这是面向维护者的调研目录，不是盲测 Agent 的默认检索库。** 正式实验通过冻结清单决定可见材料，不得把目标专用解法或未来搜索结果从研究笔记绕路注入。新增笔记应记录原始来源、版本、阅读范围、限制、提出的假设、验证设计；不提交完整论文、原始会话或受限工程产物。

本次文档整理没有更改项目的许可证、ADR 状态、运行代码或历史测量，也没有将未完成的第三方集成标为完成。

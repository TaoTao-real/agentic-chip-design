# 评估与消融协议

状态：待预注册。阈值由预实验波动和工程价值决定，不能用单次既有结果当承诺。

## 北极星

T_delivery：从共同起点到首个达到冻结最终 QoR 且通过全部最终门禁的候选的实际墙钟。包括准备、模型、查询、构建、EDA、排队、重试和最终验证。并行测真实墙钟，另报 active cost，避免重复相加。

同时报告固定预算最佳已验证 QoR、达标成功率、缓存/非缓存输入、输出/reasoning、实际费用、EDA 计算量、P&R 次数和人工。没有达标不能从统计中删除；不要只平均成功样本。

## 阶段

构建通过 ≠ 差分通过 ≠ 形式等价 ≠ 搜索晋级 ≠ 最终交付。快指标用于排序与分配预算，未经校准不能作为唯一物理裁判。最终失败后的继续/停止规则事先冻结。

## 因素矩阵

| 对照 | 改变因素 | 回答 |
|---|---|---|
| G0 / G1 / G2 | 无过程知识 / 同内容直给 / 同内容检索 | 内容收益与检索收益分开 |
| E0 / E1 | 原始工具 / 自动当前证据准备 | 提取、关联、选择是否省总成本 |
| D: 2×2 | Chisel/PyCircuit × 原始/关联反馈 | 表示、反馈主效应及交互 |
| R | 相同领域服务与输入，仅换 runtime | 运行载体的独立影响 |
| M | 留出模块开启/关闭允许历史 | 经验迁移而非回忆答案 |

## 强基线

专家 Prompt 经过设计者审阅，允许 Agent 自主 grep、查询和写脚本；同样享有正确性门禁和安全隔离。不得给基线故意不可用的日志，也不能只给实验组额外的功能边界或黄金答案。

语言迁移、清洗、知识、停止策略、模型与 DSH 不在一次主对照中同时变化。固定预算探索与达标交付分开评估。

## 统计与污染

做多个独立 Agent 请求序列；随机差分测试 seed 不等于独立搜索重复。采用配对任务和预声明统计口径，串行或严格隔离共享资源。记录实际暴露知识，不把允许访问等同已读取。

已知目标作为接入回归，新模块用于留出验证。规划仓库和历史目标补丁不能进入盲测上下文。

## 机制指标

定位所需 token/工具调用、原始字节读取、设计映射覆盖/错误率、清洗遗漏、失败到有效修改的成本、准备 CPU/墙钟、缓存使用及维护成本。Agent 引用证据的遥测只作线索，不替代关闭该证据的因果消融。
